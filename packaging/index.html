bitcalc

Bitwise calculator and base converter with step-by-step output.

Install

curl -fsSL @BASE_URL@/install.sh | bash

Uninstall

curl -fsSL @BASE_URL@/uninstall.sh | bash

Manual setup

sudo install -D -m 644 <(curl -fsSL @BASE_URL@/bitcalc-archive-keyring.gpg) /usr/share/keyrings/bitcalc-archive-keyring.gpg
echo "Types: deb
URIs: @BASE_URL@
Suites: ./
Signed-By: /usr/share/keyrings/bitcalc-archive-keyring.gpg" | sudo tee /etc/apt/sources.list.d/bitcalc.sources
sudo apt update && sudo apt install bitcalc
